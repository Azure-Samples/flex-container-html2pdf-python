# flex-container-html2pdf-python changelog

## 1.0.0 (2026-11-13)

### Features

- Python 3.15 Azure Functions Flex Consumption container.
- Bounded HTML-to-PDF rendering with Playwright and OS-installed Chromium.
- Azure Developer CLI deployment with Bicep and Azure Container Registry Tasks.
- Deterministic image tags, immutable digest deployment, and scoped read-only
  registry credentials.
- Cross-platform deployment and endpoint verification scripts.
